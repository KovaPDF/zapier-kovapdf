# Security

Please report a security problem in this app privately to **support@kovapdf.com** (the contact in https://www.kovapdf.com/.well-known/security.txt). Do not open a public issue for it.

How KovaPDF handles files, encryption and reports: https://www.kovapdf.com/security

What helps us: the app and version, what you did, what happened, and what you expected. We answer every report and say when it is fixed.

This app keeps no secrets in its code. Your KovaPDF API key stays in the platform's own encrypted connection store and is sent only to `api.kovapdf.com`, as a Bearer token.
